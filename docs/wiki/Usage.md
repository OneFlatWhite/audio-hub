# 核心概念与日常使用

## 一、订阅怎么写

订阅项页 → 新建订阅，四种类型：

| 类型 | 填什么 | 程序做什么 |
| --- | --- | --- |
| 歌手 | 中文或英文名（建议把常用别名写进「别名」，逗号分隔） | 持续追该歌手的新专辑，入库即完成 |
| 专辑 | 专辑名 + 歌手 | 只追这一张，拿到即完成 |
| 有声书 | 书名 / 作者 | 按分集追踪，进「连载」页 |
| 关键词 | 任意词 | 命中即报，建议配合待审 |

三个开关的语义：
- **达标即自动下载**（默认开）：high 置信直接派发下载，不进待审；
  关掉则所有命中进待审队列等你点采纳；
- **洗版**：已入库后出现更高质量 → 自动替换，旧版进回收区（30 天后清理，可回滚）；
- **追更多卷**：有声书按分集登记进连载，出了新卷自动抓。

**别名很重要**：站点标题写法千奇百怪（邓紫棋 / G.E.M / dengziqi），
把你知道的写法都填进别名，命中率天差地别。发现墙上的拼音歌手名
（如 qun xing）也会用你订阅里的中文名自动还原显示。

## 二、一条候选的生命周期（命中记录页的状态含义）

```
已发现 discovered → 已评分 scored → 已派发 dispatched → 下载中 downloading
→ 已完成 completed → 已归档 routed（或 已拒绝 rejected / 失败 failed）
```

- 派发后行内会出现**实时进度条**（百分比 · 速度 · 剩余时间，5 秒刷新）；
- 「已派发」但进度条不动 = 在下载器队列里排队（qb 的同时下载数限制）；
- 下载完成 → 自动进入校验：假无损 / 空包 / 扩展名检查，不合格进**隔离区**；
- 页面 30 秒自动刷新；右上角「立即同步下载器」可不等轮询立即对账。

## 三、自动化的边界（哪些事程序自己做，哪些要你管）

程序自动：RSS 捕获（默认 10 分钟）、订阅主动搜索（15 分钟）、下载完成
对账与归档、洗版升级、H&R 达标判定、通知推送、日志与事件留痕。

需要你管的：
- 站点 Cookie 过期 → 站点中心会标「认证失效」，重贴 Cookie 再测一次；
- 隔离区积压 → 定期看一眼，放行 / 丢弃；
- 想要的歌手没被抓到 → 八成是标题写法不在别名里；
- 下载器排队不动 → qb 的「同时下载数」限制，去 qb 设置里调。

## 四、发现墙

展示的是各站**真实最新上架**（RSS），不是全站搜索。用法：
- 搜索框是跨站主动搜索（歌手 / 专辑名）；
- 卡片上「追踪歌手 / 仅此专辑」一键订阅；
- Free / 2up 徽章是站点促销标记；↑数字是做种人数；
- 数据来自后台缓存：页面永远秒开，右上「刷新」转后台执行，
  也可在 config.yaml 开 `discover.auto_refresh_minutes` 定时后台刷新。
